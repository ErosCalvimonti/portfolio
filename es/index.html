Suite de tests de QuickPizza ↗

Suite de API, UI y performance para QuickPizza. Playwright + TypeScript con Page Objects y fixtures en Chromium y Firefox; tests de smoke y carga en k6 con umbrales p95/p99 por endpoint. Bugs que encontré, confirmados en el código fuente

  1. F-01Media

    Las “calorías por porción” ignoran la masa: una pizza de borde relleno parece tener 300 kcal menos de las reales.

  2. F-02Alta

    maxCaloriesPerSlice no se respeta: tras 10 reintentos la API devuelve una pizza que supera el límite, con 200 OK.

  3. F-03Baja · a11y

    Tres inputs comparten el mismo id, así que cada <label for> apunta al primero. Los lectores de pantalla no los distinguen.

Los bugs conocidos se marcan con test.fail() en vez de saltearlos: siguen visibles en cada ejecución y se ponen en rojo el día que se arreglan.
